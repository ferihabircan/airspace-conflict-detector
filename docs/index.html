Finding the moments two aircraft got too close, and seeing them coming

A Python toolkit that scans aircraft trajectories for losses of separation (under 5 NM and 1,000 ft), predicts conflicts minutes ahead from the closest point of approach, and flags overloaded sectors. Works on synthetic traffic or real OpenSky ADS-B data.

Method

Three steps, each tested against a simple reference so the fast version can be trusted.

1

Fast pair search

Checking every pair of aircraft is O(n²) per time step. Positions are projected to a local plane and indexed in a KD-tree; candidates within 5.5 NM are confirmed with the exact great-circle distance. A unit test checks the result equals brute force.

2

Closest point of approach

For each nearby pair, relative position and velocity give the time and distance of closest approach within the next 5 minutes; altitude is extrapolated with the current vertical rate. A conflict alert fires when both minima would be infringed.

3

Sector load

Airspace is split into 1°×1° cells and two flight-level bands (FL245–345, FL345+). Distinct flights per cell per 20 minutes are compared with a capacity value to flag hotspots.

Missed predictions are mostly pairs in climb or descent, where a straight-line vertical extrapolation is weak. Intent-based prediction (flight plan and performance model) is the natural next step.

Sector hotspots

Flights per 20-minute window in the busiest sectors. Cells above the capacity of flights are overloads that would call for a flow measure.

Run it yourself

git clone https://github.com/ferihabircan/airspace-conflict-detector
cd airspace-conflict-detector
pip install -r requirements.txt
PYTHONPATH=src python -m conflict_detector.cli                       # synthetic traffic
PYTHONPATH=src python -m conflict_detector.cli --opensky states.csv  # real ADS-B data
PYTHONPATH=src python scripts/export_site_data.py                    # refresh this website
PYTHONPATH=src pytest -q

Simplifications: 5 NM / 1,000 ft everywhere above FL100 (real minima depend on airspace), grid sectors instead of real sector polygons, and illustrative severity bands rather than the EUROCONTROL Risk Analysis Tool.
